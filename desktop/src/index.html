开始使用 SSH Tool

在左侧「本机」新建终端，或点击「服务器」打开 SSH 终端。

设置

服务器凭据与终端外观都保存在本机，不会上传。

服务器

点击左侧服务器打开 SSH 标签；服务器行右侧的箭头图标可打开文件传输。

外观

仅影响终端区域，应用界面保持浅色。

关于

一个 Windows 上的轻量 SSH 终端与文件传输客户端。

SSH Tool

版本 0.1.0 · Windows

支持连接 Linux、macOS、Windows 三类目标主机，内置终端与双栏文件传输。 服务器配置和密码只保存在本机，不会上传到任何服务。
